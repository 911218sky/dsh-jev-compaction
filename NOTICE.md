# NOTICE

## This repository

`dsh-jev-compaction` (911218sky) is a standalone TypeScript packaging of the
DeepSeek Harness Jev compaction plugin, adapted for DSH 0.1.7+ and for
OpenAI-compatible decision backends (chat/completions and choice-style models).

## Primary source

Based on [@yadsh/dsh-jev-compaction](https://github.com/xarleyn/dsh-plugins/tree/main/plugins/dsh-jev-compaction)
in [xarleyn/dsh-plugins](https://github.com/xarleyn/dsh-plugins) (MIT).

Shared runtime helpers may come from published packages
`@yadsh/dsh-plugin-kit` and `@yadsh/dsh-plugin-log` from the same monorepo.

## Upstream inspiration (from upstream NOTICE)

- [tamaratran/fast-jev-compaction](https://github.com/tamaratran/fast-jev-compaction) — Jev selective tool-history compaction (MIT, Copyright (c) 2025 Tamara Tran).
- Immediate result-shaping ideas were inspired by the `typesafe-result-shaper` module of [zhangxaochen/dsh-jev](https://github.com/zhangxaochen/dsh-jev) (MIT).

No API keys or secrets belong in this repository.
